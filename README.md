# Village of Schaumburg Homepage Concept

This is a homepage concept based on:
- The supplied Schaumburg RFP (2026-RFP-061)
- Phase 1 Discovery & Research
- Phase 2 Define Strategy
- The supplied Village of Schaumburg logo
- Current public Village/Cultural Center/90 North research used for content and imagery.

## Run
Open `index.html` in a modern browser.

## Notes
- The logo is the supplied image and is stored locally at `assets/images/schaumburg-logo.png`.
- Concept photography is loaded from publicly accessible web image URLs so the prototype remains lightweight. Replace these with approved/licensed production assets before launch.
- Search is a front-end interaction placeholder; connect it to the final CMS/search index during development.
- The page intentionally uses a task-first structure: Find → Do → Explore → Connect.
